# Autonomous Bird Observer

## Идея

Создать автономную систему наблюдения за птицами, которая работает 24/7 и со временем учится распознавать не только виды птиц, но и отдельных особей.

Основная идея — объединить видео, звук и историю наблюдений, чтобы система постепенно формировала собственную базу известных птиц и могла находить устойчивые особенности их внешности, поведения и вокализации.

Пример:

- `sparrow_07` регулярно появляется утром;
- система узнаёт его визуально;
- со временем накапливает связанные с ним аудиозаписи;
- обнаруживает характерные особенности голоса;
- позже может распознать `sparrow_07` только по звуку.

---

## Платформа

Основной edge-узел:

- Khadas VIM3
- камера IMX415
- микрофон или массив микрофонов
- SSD для локального хранения данных
- Amlogic NPU для vision inference
- CPU для tracking, audio processing и lightweight ML

Более мощный компьютер/GPU может периодически использоваться для обучения моделей на накопленных данных, после чего обновлённые модели снова разворачиваются на VIM3.

## Visual Re-identification

После обнаружения птицы изображение конкретной особи преобразуется в embedding — числовой вектор, описывающий визуальные признаки.

Пример:

```text
bird image
    ↓
embedding model
    ↓
[0.13, -0.52, 0.91, ...]
```

Похожие изображения должны иметь близкие embeddings.

Система может использовать:

- MobileNet
- EfficientNet
- небольшой Vision Transformer
- Siamese / Triplet-loss модель

Цель:

```text
sparrow_01
sparrow_02
sparrow_03
unknown
```

## Audio identification

Параллельно система постоянно анализирует звук.

BirdNET или аналогичная модель может использоваться не только для определения вида птицы, но и как feature extractor.

Для каждого аудиофрагмента получается embedding:

```text
audio
  ↓
BirdNET
  ↓
1024-dimensional embedding
```

Поверх этих embeddings можно обучить небольшой классификатор:

```text
BirdNET embedding
       ↓
kNN / SVM / small MLP
       ↓
sparrow_07
```

BirdNET при этом переобучать необязательно.

## Связывание изображения и звука

Главная задача — определить, какая именно птица издала звук.

Источники информации:

1. визуальная идентификация птицы;
2. положение птицы в кадре;
3. момент начала звука;
4. движение клюва;
5. направление источника звука;
6. присутствие других птиц.

При использовании массива микрофонов можно оценивать направление источника звука.

Пример:

```text
bird A: -18°
bird B: +35°
audio source: -20°

→ вероятный источник: bird A
```

Так видео может автоматически создавать разметку для обучения audio-ID модели.

## Continual learning

Система не должна обучаться после каждого кадра.

Вместо этого:

```text
24/7 inference
      ↓
collect interesting observations
      ↓
store embeddings + media
      ↓
periodic clustering / training
      ↓
evaluate new model
      ↓
deploy model
```

Обучение может выполняться раз в несколько часов или раз в сутки.

## База наблюдений

Для каждой предполагаемой особи хранится история:

```text
sparrow_07

first_seen: 2026-09-12
last_seen:  2026-09-16
observations: 1347
vocalizations: 286

visual_embeddings:
  ...

audio_embeddings:
  ...

behaviour:
  ...

relationships:
  ...
```

Для хранения метаданных достаточно SQLite.

Видео и аудио можно хранить отдельными файлами на SSD.

## Что система может изучать

Со временем система потенциально сможет находить:

- постоянных посетителей;
- время появления каждой птицы;
- предпочтительные места;
- связи между отдельными птицами;
- характерные типы вокализации;
- индивидуальные особенности голоса;
- изменение поведения со временем;
- сезонные изменения;
- появление новых особей;
- исчезновение ранее известных особей.

## Исследовательские вопросы

Проект может использоваться не только как engineering demo, но и как небольшой автономный эксперимент.

Интересные вопросы:

- Можно ли надёжно различать отдельных воробьёв визуально?
- Сохраняют ли BirdNET embeddings информацию об индивидуальном голосе?
- Можно ли распознавать конкретного воробья только по звуку?
- Есть ли у одной птицы устойчивые типы чириканья?
- Меняется ли вокализация в зависимости от присутствия других птиц?
- Есть ли устойчивые пары или группы птиц?
- Может ли система автоматически обнаруживать новых особей без заранее заданного списка?

## MVP

### Phase 1 — Data collection

- IMX415 video capture
- microphone recording
- timestamps
- bird detector
- save detected events
- SQLite database

### Phase 2 — Visual identities

- tracking
- visual embeddings
- similarity search
- clustering
- persistent bird IDs

### Phase 3 — Audio

- BirdNET embeddings
- bird vocalization detection
- synchronization with video
- audio clustering

### Phase 4 — Multimodal identification

- link audio to visually identified birds
- train individual audio classifier
- test audio-only identification

### Phase 5 — Autonomous observer

- periodic retraining
- statistics
- behavioural patterns
- timeline for each individual
- simple web UI/API
